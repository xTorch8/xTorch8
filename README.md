## Featured Projects

### 🤖 [Intelligent HR Request Management Agent](https://github.com/xTorch8/intelligent-hr-request-agent)

**Agentic RAG System for Policy-Grounded Employee Assistance and Decision Support**

An end-to-end Agentic RAG application that combines enterprise data, HR policies, deterministic business rules, and LLM-based reasoning to assist with employee HR requests.

**Highlights**

* Agentic workflow with **tool calling** and request-state management
* **Policy document ingestion and semantic retrieval**
* Employee and request data retrieval from **PostgreSQL**
* Deterministic business-rule validation before recommendations
* HR approval workflow with **auditable decision history**
* Streaming agent interaction using **SSE**

**Stack:** `Python` `LangChain` `FastAPI` `PostgreSQL` `Azure Blob Storage` `React` `TypeScript`

### 📊 [Retail Data & AI Platform](https://github.com/xTorch8/retail-data-ai-platform)

**End-to-End CDC, ELT, and Natural Language Analytical Platform**

An end-to-end data and AI platform that captures changes from PostgreSQL, transforms data through a Snowflake Medallion Architecture, and exposes analytical data through a natural-language interface.

**Highlights**

* PostgreSQL **CDC** using Airbyte
* Snowflake **Bronze → Silver → Gold** architecture
* Snowflake **Streams, Tasks, and Dynamic Tables**
* Near-real-time analytical data pipelines
* Agentic SQL interface with **schema-aware tool calling**
* SQL and prompt guardrails for safer natural-language analytics
* Intelligent model routing for analytical workloads

**Stack:** `PostgreSQL` `Airbyte` `Snowflake` `Python` `LangChain` `FastAPI`
